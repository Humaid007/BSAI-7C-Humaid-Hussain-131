Week 3 — Part C: Prove the palette, do not claim it

Contents
- palette_check.py: reproducible CVD simulation and worst-pair analysis
- taskC_palette_check.ipynb: notebook version of the analysis
- vizlib.py: course helper library supplied for the task
- PART_C_REPORT.md: written interpretation and findings
- worst_pair_results.csv: worst pair and Delta E for each palette/vision condition
- PNG files: original swatches and deutan/protan/tritan simulated swatches

Run
1. Keep palette_check.py and vizlib.py in the same folder.
2. Install numpy and matplotlib if they are missing: %pip install numpy matplotlib
3. Run: python palette_check.py

The selected comparison palette is Matplotlib tab10's first four colours. This is a diagnostic example, not a recommendation. The course's fourth colour is shown separately and should only be used with a second visual encoding such as direct labels or marker shapes.
