CDB601220 Week 3 Bonus — Pop-out experiment

IMPORTANT
This package contains the experiment runner, not fabricated classmate results.
Run it with five classmates in person to obtain actual times and the required chart.

Install:
    python -m pip install matplotlib pandas numpy

Run:
    python popout_experiment.py

The script presents four counting panels in a shuffled order for each of five
participants, records time to press ENTER after counting, asks for the response,
writes popout_experiment_results.csv, and creates popout_experiment_chart.png.
Use anonymous participant codes. Follow your instructor's intended panels 1–2
if their exact Week 1 stimuli were provided separately; the script uses clear
baseline grids because those exact panel definitions were not included with the
assignment text in this conversation.

All stimuli are generated for CDB601220. Any numbers quoted from the experiment
must be based on the actual collected data. Do not submit invented participant
times. Chart source note states n=5 and that panel order was independently
randomised for each participant.
